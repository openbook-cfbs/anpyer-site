常见问题

能额外安装 Python 包吗？

运行时不能。Android 不允许应用加载未随包分发的原生代码，因此包集合在构建期就固定了。完整清单见 第三方声明。如果你需要的包缺失，请告诉我们——纯 Python 包和许多 C 扩展包都可以在后续更新中加入。

我的 notebook 存在哪里？

存在你保存的地方。AnPyer 使用 Android 系统文件选择器，文件就在你选择的目录里（设备存储、SD 卡，或与 Android 集成的网盘应用）。notebook 打开期间，AnPyer 会在自己的私有沙箱里保留一份工作副本，保存时同步回原位置。

AI 助手提示未配置模型

助手需要你自己的 API key，来源可以是 DeepSeek、OpenAI、Google Gemini、OpenRouter 等（任何 OpenAI 兼容端点均可）。打开 ⋯ → AI 设置，选择服务商，粘贴 key，然后点 刷新模型 并选一个。key 只存在你的设备上。

cell 卡住了

点 cell 上或状态栏中的 ■ 按钮中断它。如果几秒内没有响应（在运行原生代码，例如一次很长的 numpy 运算时可能发生），请用 ⋯ → 重启内核。重启会清空所有变量，但 notebook 内容不受影响。

如何删除应用存储的全部数据？

⋯ → 关于 → 清除本地数据 会删除服务商设置、API key、最近文件列表和 AI 举报记录。卸载应用效果相同。你保存在其他位置的 notebook 文件不受影响——请用文件管理器自行删除。

报告 AI 回复
