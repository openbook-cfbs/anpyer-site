工作流

用 Python 算，用 Web 渲染。

AnPyer 的输出区是一个完整的 Web 渲染器。交互图表、Mermaid 流程图、LaTeX、HTML——浏览器能画的，cell 就能显示。

  1. 1先把数算出来numpy、pandas、scipy——重活留在 Python 里，那是它该在的地方。
  2. 2把结果交出去让 AI 助手照着结果画图，或者自己调 anpyer.plot，传一个普通 dict 就行。
  3. 3得到一张交互图ECharts、plotly、Mermaid、MathJax——直接渲染在输出区，手机上可以双指缩放。

先说清楚

AnPyer 不做什么。

我们宁愿你买之前就知道。

  • 没有 pip install包集合在构建期固定。缺你要的包？告诉我们。
  • matplotlib 是静态图图形渲染为图片。要交互，用 plotly 或内置的 ECharts 渲染。
  • C 扩展无法中断和桌面 Jupyter 一样：卡在编译代码里的 cell 需要重启内核。
