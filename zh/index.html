真正的 Python notebook

真 IPython 内核，NumPy、SciPy、pandas 一个不少。

打开任意 .ipynb，运行 cell，得到表格和图。解释器是运行在应用进程内的 CPython 3.13——不是浏览器标签页里的服务器，也不是远程沙箱。

  • 真 IPython。Tab 补全、? 帮助、magic 命令、中断与重启。
  • 100% 标准 .ipynb。文件与桌面端 Jupyter、VS Code 完全兼容——双向都行。
  • 离线可用。你的代码从不离开设备去运行。

你的文件

处理你自己的数据。任何文件夹都能当工作区。

授权 notebook 所在的文件夹，pd.read_csv("sales_data.csv") 直接就能用。Python 写出的文件会同步回那个文件夹。

  • 不要整盘存储权限。AnPyer 走 Android 系统文件选择器，只看得见你选的那个文件夹。
  • 普通文件，没有锁定。笔记本上写的 notebook，手机上改，再回笔记本打开。

可选 AI 助手 · 自带 key

cell 交给 AI。少打字，多做事。

助手在你的 notebook 里面工作，不是旁边开个聊天框。它读你的 cell 和输出，修改或插入 cell——而且只要你在本次会话里拨开「起飞」，它还能运行 cell、读结果或 traceback、然后修正自己的错误。

  • 每一步你来批准。每次修改落地前都有确认卡；每次接受的修改就是一步撤销。
  • 你的 key，你选的服务商。任何 OpenAI 兼容端点都行。便宜档模型就够用——重活由我们的 prompt 和工具扛。
  • 只在你允许时才跑代码。一次拨动，只管本次会话，重开应用即恢复关闭。

方向盘在你手里

AI 不会失控。任何 cell 都能隐藏或锁定。

把一个 cell 标为隐藏，助手拿不到它的源码、输出和哈希——它根本不知道里面有什么。标为锁定，助手能读但永远改不了。

  • 运行 cell 是会话级授权。默认关闭，重开应用再次关闭。
  • 读取 notebook 文件夹里的文件是另一个开关，在 AI 设置里，默认关闭。
  • 没配 key 就没有网络。没有设置服务商时，应用不发起任何请求。

Python 算 · AI 表达 · Web 显示

前端？等等，什么？Python 算数，TS 渲染。

AnPyer 的输出区是一个完整的 Web 渲染器。上一格用 Python 把数算出来，对助手说一句「画出来」，它就把下一格写成一张可交互的 ECharts 图——你一行画图代码都不用写，也不需要执行：渲染器直接画。

  • 三层各干最擅长的事。Python 负责数学，模型负责表达，浏览器负责像素。
  • 也可以自己来。anpyer.plot 传一个普通 dict 就能同样渲染——而且它在 PyPI 上，notebook 拿到桌面 Jupyter 也能打开。

富输出

一图胜千言。有 AI，即刻出图。

Markdown、LaTeX 公式、Mermaid 流程图、Graphviz DOT、化学结构式（SMILES）、可交互的 ECharts 和 plotly——Markdown cell 和代码输出共用同一套渲染器。桌面 Jupyter 每一样都要装扩展，这里全部内置。

  • 双指缩放。任何图表、流程图都能全屏打开，支持触控手势。
  • matplotlib 还是你熟悉的那个。图形渲染为图片，中文标签正常显示——没有豆腐块。
