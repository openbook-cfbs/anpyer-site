Real Python notebook

A real IPython kernel. NumPy, SciPy & pandas included.

Open any .ipynb, run cells, get tables and plots. The interpreter is CPython 3.13 running inside the app — not a server in a browser tab, not a remote sandbox.

  • True IPython. Tab completion, ? help, magics, interrupt and restart.
  • 100% standard .ipynb. Files stay compatible with Jupyter and VS Code on desktop — in both directions.
  • Works offline. Your code never leaves the device to run.

Your files

Process your own data. Any folder can be your workspace.

Grant access to the folder your notebook lives in, and pd.read_csv("sales_data.csv") just works. Files Python writes are synced back to that folder.

  • No broad storage permission. AnPyer uses the Android file picker and only sees the folder you choose.
  • Plain files, no lock-in. Write a notebook on your laptop, edit it on the phone, open it again on the laptop.

Optional AI assistant · bring your own key

Cells, handled by AI. Type less, do much more.

The assistant works inside your notebook, not in a side chat. It reads your cells and their outputs, edits or inserts cells — and, only if you flip the switch for the session, runs a cell, reads the result or the traceback, and fixes its own mistakes.

  • You approve each step. Every edit shows a confirmation card before it lands; every accepted change is one Undo step.
  • Your key, your provider. Any OpenAI-compatible endpoint works. Budget models do the job — our prompts and tools carry the heavy lifting.
  • It runs code only when you let it. One tap, per session. Off again when you relaunch.

You stay in the driver's seat

AI not going rogue. Hide or lock any cell.

Mark a cell hidden and the assistant gets no source, no outputs, no hash — it does not know what is there. Mark it locked and the assistant can read it but never change it.

  • Running cells is a per-session permission. Off by default, off again on relaunch.
  • Reading files in the notebook folder is a separate switch in AI settings, off by default.
  • No key configured, no network. Without a provider set up, the app makes no requests at all.

Python computes. AI expresses. The web displays.

Frontend, wait what? Py crunches, TS renders.

AnPyer's output area is a full web renderer. Crunch the numbers in one cell, ask the assistant to “plot it”, and it writes the next cell as an interactive ECharts chart — no plotting code on your side, nothing to execute: the renderer draws it instantly.

  • Three layers, each doing what it does best. Python for the math, the model for the expression, the browser for the pixels.
  • Or do it yourself. anpyer.plot takes a plain dict and renders the same way — and it's on PyPI, so the notebook still opens on desktop Jupyter.

Rich output

Graphs > 1000 words. Instant with AI.

Markdown, LaTeX math, Mermaid diagrams, Graphviz DOT, chemical structures (SMILES), interactive ECharts and plotly — in Markdown cells and in cell output, with the same renderer. Desktop Jupyter needs an extension for each of these; here they are built in.

  • Pinch to zoom. Any chart or diagram opens full-screen with touch gestures.
  • matplotlib as you know it. Figures render as images, CJK labels included — no tofu boxes.
